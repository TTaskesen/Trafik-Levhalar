# GitHub Pages gizlilik politikası

GitHub Pages için yayınlanacak dosya `privacy/index.html` konumundadır. GitHub'da **Settings → Pages** altında yayın kaynağı olarak bu dalın `/docs` klasörünü seçin. Yayın yapılmadan önce bu klasörde anahtar, test verisi veya kişisel belge olmadığını kontrol edin.

Yayın sonrası beklenen adres biçimi:

`https://ttaskesen.github.io/Trafik-Levhalar-/privacy/`

Bu adres örnektir; GitHub Pages ekranında gösterilen gerçek HTTPS adresini Play Console'a girin. Özel alan adı kullanılırsa, GitHub ayarlarından yapılandırın ve alan adını doğrulayın.
